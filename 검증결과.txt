Ransom0 Preview16 검증 결과 — 2026-11-20

포함 변경
- Rule #1001을 Track A 예방 차단으로 표시합니다.
- 규칙 설명 및 실제 자식 생성 차단을 부모 종료·격리·복구와 구분합니다.
- 시험/운영/미분류는 원본 evidence를 따릅니다. 과거 기록을 임의로 시험 또는 운영으로 바꾸지 않습니다.
- 정상 관리 명령도 일치할 수 있으므로 Rule1001 단독으로 악성 확정이라고 표시하지 않습니다.

코드·배포 파일 검증
- UI 42개, 설치기 18개, Track A/프로그램 예외 14개 시험 통과.
- UI lint/Windows 빌드 통과. 압축 payload 375개 파일 해시 일치.
- 설치 payload의 실제 UI 번들에 새 Track A / VSS 스냅샷 삭제 시도 표시 포함 확인.
- 비밀정보 패턴 검사 통과. API 키는 배포하지 않습니다.

VM 검증

- 신규 설치: DEFERRED by user: test-signing configuration change not authorized; installation refused at prerequisite check
- 재부팅: DEFERRED: post-installation reboot not performed

검증 한계
- 실제 JEV Track A/B 부모 강제 종료·복구 전체 성공을 이번 검증으로 주장하지 않습니다.
- 이전 Preview15의 12만 쓰기/12파일 VSS 복구 결과는 별도 이전 보고서입니다. 이번 실행 결과와 구분합니다.
- Rule1001 표시 변경은 탐지 임계값을 완화하거나 부모 프로세스를 무조건 종료하도록 만드는 변경이 아닙니다.
- Microsoft 정식 배포 서명판이 아닙니다. 물리 PC 및 타 백신 공존은 별도 시험이 필요합니다.
- 유실 카운터를 초기화하거나 실패 기록을 삭제하지 않았습니다.
