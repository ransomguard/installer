# Ransom0 preview.25 — 학교 시험 VM용

## 설치 및 이동

1. 이 파일은 일반 노트북에서 실제 랜섬웨어를 실행하기 위한 도구가 아니다. 준비된 Windows x64 시험 VM 안에서만 설치한다.
2. VMware를 정상 종료한 뒤 VM 전체 폴더를 옮긴다. 기존 VM을 이동한 경우 VMware 질문에 `I Moved It`을 선택한다. 복사본이면 실제 상황에 맞게 선택한다.
3. `SHA256SUMS.txt`와 설치파일 해시를 대조한다. `Ransom0-Check.exe`로 시험 VM의 설치 조건을 확인한다. 시험 서명·Secure Boot 조건은 자동 변경하지 않는다.
4. `Ransom0_install.exe`를 관리자 실행하여 설치/업데이트한다. 설치 후 바탕화면 `Ransom0`는 대시보드, `Ransom0_install`은 설치 및 관리를 연다.
5. 새 VM에서는 JEV 키와 보호·복구 폴더를 직접 설정하고 유효한 복구 기준이 생성됐는지 확인한다. 키·기존 데이터베이스·시험 파일·악성코드는 설치파일에 포함하지 않는다. 기존 설치 업데이트는 기록과 설정을 유지한다.
6. 기존 Core 드라이버가 8192 큐 버전이면 직접 업데이트가 거부될 수 있다. 임의 드라이버 삭제나 강제 교체하지 말고, 별도 통제된 업그레이드 또는 깨끗한 시험 VM을 사용한다. 이번에 검증한 VM의32768 큐 드라이버와는 해시가 일치한다.

설치/업데이트는 수집기 재시작을 포함할 수 있으며 그동안 보호 공백이 발생한다. 악성코드가 실행 중이거나 대응·격리 보류가 남은 상태에서는 설치하지 않는다. 설치·재시작 후 정상 수집·대응·복구 준비를 다시 확인한다.

## 포함 구성과 제한

- Core 큐32768, 기존 Filter, 현재 백엔드 및 새로 빌드한 UI. JEV 악성 기준0.8 및 수집·저장 내구성 변경 없음.
- 시험 서명 패키지이며 Microsoft 정식 배포 서명 제품이 아니다.
- 구성 요소 VM 검증: 12만 쓰기에서 추가 유실0, 처리226.68초. A 자동 종료·복구 통과.
- 마지막 B는 JEV0.79로 검토 필요에 머물러 자동 종료·복구 미통과. 수동 시험 정리로 원본12개를 복구했으며 원래 실패 기록을 보존했다.
- 위 결과는 기존 VM에 적용한 구성 요소 시험이다. 새 preview.25 통합 설치본의 실제 설치·재부팅 검증은 별도 결과가 없는 한 미완료다.
- 새 릴리스는 모든 랜섬웨어 탐지, 무제한 무유실, 무오탐을 보증하지 않는다.

## 실제 샘플 실행 전 필수 확인

설치파일은 VM 격리 환경을 자동 구성하지 않는다. 샘플 실행은 다음 확인 후 별도로 진행한다.

- 시험 VM은 호스트 어댑터 없는 전용 가상망에 연결하고 직접 NAT/브리지 경로를 제거한다.
- 별도 게이트웨이에서 기본 외부 차단, JEV 통신만 제한적으로 허용한다. 호스트·학교 내부망 및 IPv6 우회 경로를 차단한다.
- 공유 폴더, 클립보드, 드래그앤드롭, USB 자동 연결을 해제한다. 감염 상태에서 재연결하지 않는다.
- 통제된 시험 서버에 대해 탐지 전 연결 성공/탐지 후 차단을 서버 측 패킷으로 확인한다. 정책 ACK만으로 차단 성공으로 판정하지 않는다.
- 정상 설치·설정·복구 기준이 준비된 VMware 초기화 스냅샷을 만든다. 제품의 VSS와는 별개다.
- 학교 장비로 이동한 뒤 네트워크 격리를 재검증하고 샘플별로 초기화한다. VM만으로 호스트 피해 가능성0을 보장하지 않는다.

이 문서는 준비 안내이며, 학교 VM 격리 완료나 실제 샘플 시험 완료 인수인계서가 아니다.
