# RansomGuard 통합 시험 설치본

## 다운로드

[Releases](https://github.com/ransomguard/installer/releases)에서 **v0.6.0-preview.3** 파일을 받으세요. GitHub의 Source code ZIP은 설치 파일이 아닙니다.

- `RansomGuard-Lab-Setup.exe`: 격리된 Windows x64 VM용 통합 설치 후보.
- `RansomGuard-Check.exe`: 설치 가능 여부를 읽기 전용으로 검사하는 도구.
- `RansomGuard-TestPC-Setup.exe`: 관리자 승인을 받아 시험 드라이버 실행 환경을 이미 준비한 전용 시험 PC용. 일반 학교/개인 PC에 바로 설치하는 정식 제품이 아닙니다.
- `SHA256SUMS.txt`: 파일 무결성 확인값.

통합 EXE에는 Python 런타임, UI, 복구 백엔드, 드라이버, 방화벽 구성요소와 JEV 브리지가 포함됩니다. 사용자가 네 저장소를 따로 받아 파이프라인을 연결할 필요는 없습니다. 설치 화면에서 보호 폴더 등 필요한 설정을 선택합니다. 실제 JEV 키는 포함하지 않으며 별도로 입력해야 합니다.

## 사용 전 확인

1. 전용 시험 VM의 기준 스냅샷을 확보합니다.
2. 검사 도구로 설치 가능 여부를 확인합니다.
3. VM용 설치 EXE를 실행하고 설치 화면 안내를 따릅니다. 준비 조건이 충족되지 않으면 설치가 거부됩니다.
4. 설치 관리자에서 상태를 확인하고 대시보드를 실행합니다.

Microsoft 배포 서명과 정식 할당 altitude가 없는 시험 드라이버입니다. 설치 프로그램은 Secure Boot, 시험 서명 설정, Windows 계정 암호를 자동 변경하지 않습니다. 기본 보안 설정의 일반 PC에서 즉시 사용 가능한 제품이라고 보증하지 않습니다. TestPC 모드는 PC 전체 통신 제한에 대한 명시적 확인을 요구합니다.

JEV 키/통신이나 유효한 복구 준비가 없으면 자동 대응 준비 완료로 간주하지 않습니다. 기존 사건·복구·검토 hold는 설치/제거 시 임의 삭제하지 않습니다.

## 검증 범위

- 백엔드 단위 시험 376개 통과 기록이 있습니다.
- 이전 preview.2는 기존 Windows 11 시험 복제 VM에서 설치·재부팅·제거를 검증했습니다. 이 결과를 preview.3의 새 Windows 11 검증으로 대신하지 않습니다.
- 이번 preview.3의 완전히 새 Windows 11 VM 설치·재부팅·복구·제거 검증은 **미완료**입니다. 따라서 prerelease로 게시합니다.
- Windows 10 새 VM에서 preview.3 압축 해제는 확인했으며 전체 설치 검증은 하지 않았습니다.
- UI app.asar는 기존 번들과 동일합니다. 실제 JEV 탐지 정확도나 모든 환경에서 이벤트 유실 0을 보증하지 않습니다.

## 소스와 구성

`src/`는 설치·상태 검사·실행 관리 코드, `backend/`는 이 설치 후보에 포함된 복구 코드 스냅샷, `tests/`는 설치 코드 시험입니다. 백엔드의 기존 버전 문자열만으로 공개 restore 태그와 바이트 단위 일치를 가정하지 마세요. 이 후보에는 이후 변경도 포함됩니다.

`build-reference.py`는 제작 환경의 빌드 레시피입니다. 기존 바이너리 payload와 드라이버 입력 경로를 사용하므로 이 저장소만으로 재현 가능한 전체 빌드를 제공하지는 않습니다. 실행은 Releases의 통합 EXE를 이용하세요. 커널/복구 새 패치 버전 게시 상태는 각 저장소에서 별도로 확인하세요.

UI와 방화벽 담당 저장소의 최신 팀 변경을 이 저장소가 덮어쓰지 않습니다. 설치본에 포함된 정확한 파일 해시는 `payload-manifest.json`으로 확인할 수 있습니다.
